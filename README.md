# Contact-Manager
Smart Contact Directory with Intelligent Search functionality

## Tech Stack
- Flask APIs for backend
- Simple Jinja supported HTML CSS frontend
- MongoDB for persistent storage

## Scope
- basic contact details: name, phone number, email
- able to store, edit, delete and display contacts
- filter and sort features on available contacts
- searching for finding contacts
